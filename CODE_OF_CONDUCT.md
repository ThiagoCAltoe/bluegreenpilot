# Code of Conduct

## Our Pledge

We want BlueGreenPilot to be a practical, respectful, and safe open source
project for people working on deployment workflows, coding agents, and release
engineering.

Everyone participating in this project is expected to treat others with
respect, assume good faith, and keep discussions focused on improving the
project.

## Expected Behavior

- Be respectful and constructive.
- Discuss technical disagreements with specific examples and evidence.
- Be mindful that deployment and production safety are high-stakes topics.
- Help contributors understand project safety rules before proposing risky
  automation.
- Report security-sensitive issues privately when possible.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without consent.
- Encouraging unsafe production actions, secret exposure, or destructive
  automation without clear safeguards.
- Repeatedly derailing issues or pull requests after maintainers ask you to
  stop.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block users, or
take other reasonable actions to protect the project and its contributors.

Reports will be reviewed by the maintainers. If you need to report a concern,
contact the repository maintainer through the contact information available on
their GitHub profile until a dedicated project contact is published.

## Scope

This code of conduct applies to project spaces including GitHub issues, pull
requests, discussions, documentation, and community channels associated with
BlueGreenPilot.
